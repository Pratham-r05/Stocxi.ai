Project Summary

Built a production-grade stock intelligence system for Indian markets. The platform fetches price, fundamentals, financial statements, technical indicators, news, and announcements. It normalizes them into auditable data nodes, builds a knowledge graph, and returns clear user-facing analysis without making investment-advice claims.

Core Product Flow

1

Search any Indian stock

Users search NSE/BSE symbols and open a rich stock overview.

2

Fetch verified market data

Backend pulls from approved exchange, Screener, RSS, and fallback sources.

3

Build evidence graph

Signals become typed nodes connected by agreements, contradictions, and context.

4

Generate verified analysis

AI output is checked so uncited claims are stripped before users see them.

System Architecture

Frontend Next.js dashboard with search, charting, fundamentals, AI analysis, filings, news, and graph views.
Backend FastAPI routers, service layer, source fetchers, cache, and report endpoints.
Agents Technical, fundamental, news, announcement, context, analysis, verifier, and formatter agents.
Data Layer NSE, BSE, Screener, yfinance fallback, approved RSS sources, Redis, and audit logs.
Trust Layer Anonymization, sanitizer, source priority, data completeness checks, and citation verification.
